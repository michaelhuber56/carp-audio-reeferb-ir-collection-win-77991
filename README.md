## About CARP Audio Reeferb IR

CARP Audio Reeferb IR is designed for audio work that depends on realistic reverb textures and flexible impulse response handling. It brings an IR library into a plugin-friendly workflow, making it useful for mixing, sound design, post-production, and other tasks where convolution-based space shaping matters.

The project supports Windows, macOS, and Linux, with plugin formats that include VST3, AU, AAX, and LV2. Its focus on a large IR set, responsive controls, and modern language support makes it easier to navigate large reverb collections while keeping creative control close at hand.
